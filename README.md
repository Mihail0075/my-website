# Автобуска Станица Прилеп

Информативен сајт со распоред на поаѓања од/за автобуската станица во Прилеп —
статичен HTML/CSS/JS, без build-чекор и без зависности.

## Стартување

Отвори `index.html` во прелистувач, или подигни локален сервер:

```
python3 -m http.server 8000
```

потоа отвори <http://localhost:8000>.

## Структура

| Датотека     | Што содржи                                                            |
| ------------ | --------------------------------------------------------------------- |
| `index.html` | Структура на страната (навигација, hero, дестинации, распоред, инфо)   |
| `style.css`  | Целосен стил и одзивен распоред                                       |
| `data.js`    | Возен ред: `CARRIERS`, `GROUPS`, `DEST` (од Прилеп), `INBOUND` (за Прилеп) |
| `script.js`  | Преводи (МК/EN), рендерирање на градови и распоред, пребарување, филтри |
| `assets/`    | `logo.png`, `hero.jpg`                                                |

### Формат на податоците

Секое поаѓање во `DEST`/`INBOUND` е низа:

```
[час, превозник, цена, повратна, денови]
```

- `превозник` — индекс во `CARRIERS`
- `цена` / `повратна` — во денари (`0` = нема податок)
- `денови` — битова маска: `1`=пон, `2`=вто, `4`=сре, `8`=чет, `16`=пет, `32`=саб, `64`=нед
  (`127` = секој ден, `63` = пон–саб, `31` = пон–пет)

Познатите отстапувања меѓу печатениот ценовник и податоците од API-то се
наведени во коментарот на врвот од `data.js`.
