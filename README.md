# My Website

A personal website built with HTML and CSS.

## Getting started

Open `index.html` in your browser — no build step needed.

## Автобуска табла (`avtobuska/`)

Информативна табла за заминувања од Автобуска станица Прилеп, во стил на
аеродромските „split-flap“ табли. Отворете `avtobuska/index.html` во прелистувач.

- **Табла** — следните поаѓања со време, линија, дестинација, превозник, перон и
  статус (закажан, навреме, качување, последен повик, заминат). Текстот се менува
  наизменично на македонски и англиски.
- **Линии** — целосен возен ред по дестинација, со пребарување (кирилица или латиница).
- Возниот ред е во `avtobuska/vozen-red.js` — само таа датотека се менува при нов возен ред.
- Параметри: `?redovi=12` (број на редови), `?jazik=mk` (фиксен јазик),
  `?vreme=08:00` (симулирано време за проба). Копчето **F** ја става таблата на цел екран.

> Термините се ориентациски: официјалниот сајт avtobuskaprilep.mk не беше достапен
> при изработката. Внесете го официјалниот возен ред во `vozen-red.js` и поставете `verified: true`.
