## Идејата (со твои зборови, средено)

Стартап за пратки што стигнуваат **истиот ден** со автобус: од автобуската станица во Прилеп до автобуската станица во Скопје и обратно, преку линискиот превозник. Пратката се плаќа на почетната станица, се внесуваат тежина, големина и податоци за праќачот. Примачот ја подига од **сандак на станицата** со PIN, или ја зема **курир** (Wolt, Korpa…) до адреса.

## Што е направено (верзија 1)

Детално: `README.md` и `docs/SPECIFIKACIJA.md`. Накратко:

- **Киоск**: подигање со PIN или QR, оставање со код за оставање, праќање со картичка (симулирано), режим за возач со службен PIN, мапа на сандаците, македонски и англиски, враќање на почеток по неактивност.
- **Шалтер (Прилеп)**: прием со готовина или POS, број на пратка и PIN, налепница 100 × 150 mm, предавање по PIN.
- **Возач**: натовар, истовар (системот доделува сандак по големина), „Ставено ✓“, поголем сандак, вадење истечени.
- **Админ**: пратки, сандаци во живо (симулатор), активирање киоски, испратени пораки.
- **Хардвер**: протокол `/api/hw` + референтен контролер `hardware/controller.py` (нетестиран на вистински хардвер).
- 25 тестови и тест на целиот тек во прелистувач. Сите поминаа.

**Симулирано засега:** плаќањето со картичка и сандаците. Е-поштата се зачувува во админ → „Пораки“ додека не се постави SMTP.

## Отворени прашања (чекаат одговор)

1. Име на фирмата/брендот (сега привремено „Брза Пратка“).
2. Дали привремените цени се во ред: мала 150, средна 200, голема 250 ден. + тежина (до 2 kg +0, до 5 +50, до 10 +100, до 20 +150)?
3. Што по 24 часа: враќање кај праќачот (со доплата?), чување во канцеларија, или автоматско продолжување?
4. Прилеп: сандаци и киоск, или само шалтер?
5. Печатач за налепници на шалтерот? Во Скопје: печатач на киоскот, или праќачот го пишува бројот со маркер?
6. Тежина при самоуслуга (нема вага): дали возачот проверува и наплаќа разлика?
7. „Не собира“ при оставање: поголем сандак со доплата на самиот киоск?
8. Возачите: колку ќе бидат? Вработени кај превозникот?
9. Дали станиците и киосците се достапни 24/7?
10. Хостинг: Vercel + Neon (PostgreSQL), или VPS во ЕУ?

## Следни чекори (предлог)

1. Одговори на отворените прашања, па прилагодување на правилата во `src/lib/config.ts`.
2. Вистински хардвер за сандаците во Скопје: контролер, брави и сензори преку постоечкиот `/api/hw`.
3. Вистинско плаќање (платежна порта + POS на киоскот) и фискални сметки.
4. Работа на киоскот без интернет (локална проверка на PIN на контролерот).
5. Viber пораки, повикување курир, извештаи. Веб-страницата кога ќе дојде на ред.

## Стартување на нов компјутер

Потребно: **Git**, **Node.js 22+**, **PostgreSQL 14+**.

```bash
git clone https://github.com/Mihail0075/my-website.git
cd my-website
git checkout claude/hopeful-hypatia-dkw8sg
npm install
cp .env.example .env        # DATABASE_URL кон вашата база, SESSION_SECRET = долг случаен текст
npm run db:migrate
SEED_ADMIN_PASSWORD=Admin-demo-2026 SEED_ADMIN_PIN=739154 \
SEED_COUNTER_PASSWORD=Salter-demo-2026 \
SEED_DRIVER_PASSWORD=Vozac-demo-2026 SEED_DRIVER_PIN=482913 npm run db:seed
npm run dev                 # http://localhost:3000
```

Демо-најави (**само за локално пробување**, никогаш во продукција):

| Корисник | Лозинка | Службен PIN |
|---|---|---|
| `admin` | `Admin-demo-2026` | `739154` |
| `salter.prilep` | `Salter-demo-2026` | — |
| `vozac` | `Vozac-demo-2026` | `482913` |

Потоа: најава како `admin` → **Киоски** → активирај уред за Скопје → одјава. Целиот тек е опишан во `README.md`, во делот „Пробување на целиот тек“.

На Windows, PowerShell не ја прифаќа синтаксата `SEED_...=... npm run ...`. Поставете ги променливите со `$env:SEED_ADMIN_PASSWORD="Admin-demo-2026"` (и така за секоја) и потоа `npm run db:seed`.
