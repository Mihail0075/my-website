# Безбедност — основа и што следува

## Што е направено

| Слој | Состојба |
|---|---|
| Најава на персонал | Лозинки со scrypt. Сесии во базата (одјавата важи и на серверот), HttpOnly/SameSite колачиња, `Secure` во продукција. 5 неуспешни најави → 15 минути заклучување |
| Киоск | Само уреди регистрирани од администратор (потпишано колаче по станица, може да се поништи). PIN за подигање: 4 цифри, единствен по станица, без лесни комбинации. 5 погрешни → 5 минути заклучување. QR кодот носи долг случаен токен |
| Возач на киоск | Службен PIN (6 цифри, во базата само HMAC), сесија 10 минути, само за таа станица |
| Контролер на сандаци | Таен клуч по станица, во базата само HMAC |
| CSRF | Секое барање што менува податоци мора да дојде од истиот домен (проверка на `Origin`) |
| Пристап | Секоја API акција проверува улога и станица на серверот, не само во интерфејсот |
| Податоци | Drizzle ORM (параметризирани барања). Јавното следење не прикажува имиња, телефони ни кодови |
| HTTP заглавја | HSTS, X-Content-Type-Options, X-Frame-Options DENY, Referrer-Policy, Permissions-Policy, основен CSP |
| `/.well-known/security.txt` | Постои. **Сменете ја е-поштата за контакт** |

## Пред пуштање во употреба (по приоритет)

1. **Висок:** долг случаен `SESSION_SECRET` во продукција. Без него, во продукција одбива секоја операција што потпишува (киоск, службен PIN, контролер). HTTPS насекаде.
2. **Висок:** двофакторска најава (2FA) за администраторите.
3. **Висок:** вистинска платежна порта со потпишан callback. Потоа `PAYMENT_MODE=live`, со што се исклучува симулираното плаќање.
4. **Среден:** CSP со nonce наместо `'unsafe-inline'`.
5. **Среден:** рок за чување лични податоци (на пр. бришење имиња/телефони по 6 месеци) и политика за приватност (Закон за заштита на личните податоци).
6. **Среден:** дневни резервни копии на базата и проба за враќање. Надзор (грешки, неуспешни најави).
7. **Низок:** преглед на пристапите секој квартал. Автоматски известувања за ранливости во пакетите.

## Познат компромис

PIN-от е само 4 цифри за да биде лесен. Заштитата е во ограничувањето на обидите по киоск, во тоа што PIN-от важи само на станицата каде е пратката, и во рокот од 24 часа. Ако некој намерно ја заклучува тастатурата, тоа ги попречува и другите 5 минути. Тоа се гледа во логовите, а примачот може да го користи QR кодот.
